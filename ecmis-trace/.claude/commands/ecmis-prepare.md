อ่าน `CLAUDE.md` ให้ครบก่อนเริ่ม และทำตามกติกาในนั้นตลอดงานนี้

## ขอบเขต
- **ห้ามแตะไฟล์ Excel ใด ๆ** (template และ output)
- ห้ามแก้ไฟล์ใน `input/`

## ขั้นตอน
1. ลิสต์ไฟล์ทั้งหมดใน `input/docs/` (PDF, DOCX, XLSX, รูปภาพ ฯลฯ) ถ้าไม่มีไฟล์ให้หยุดและแจ้งผู้ใช้
2. แปลงแต่ละเล่มเป็นข้อความ บันทึกที่ `work/docs/{ชื่อไฟล์เดิม}.md` โดย **ทุกหน้าต้องมีเลขหน้ากำกับ** รูปแบบ:
   ```
   ===== หน้า 12 / 240 =====
   (ข้อความของหน้า)
   ```
   - PDF: ใช้เลขหน้าของไฟล์ ถ้าเลขหน้าที่พิมพ์ในเล่มต่างจากเลขหน้าไฟล์ ให้ใส่ทั้งสองแบบ เช่น `===== หน้า 12 (เลขในเล่ม: 8) =====`
   - DOCX: ใช้ page break / section ที่มี ถ้าไม่มีเลขหน้าจริงให้ระบุว่าเป็นเลขลำดับโดยประมาณ
   - ตารางให้คงเป็นตาราง Markdown เท่าที่ทำได้
3. ถ้าหน้าไหนเป็น **ภาพสแกน** (ดึงข้อความไม่ได้หรือได้น้อยผิดปกติ) ให้ OCR ภาษาไทย+อังกฤษ และ
   - ใส่ป้าย `[OCR]` ที่หัวหน้านั้น
   - แจ้งเตือนผู้ใช้ว่า **OCR ภาษาไทยอาจคลาดเคลื่อน** (สระ/วรรณยุกต์หาย, รหัส LAW/SDD/Page Code อาจอ่านผิด) และระบุรายการหน้าที่เป็น OCR
   - ห้ามแก้ข้อความ OCR ด้วยการเดา
4. สร้าง `work/docs/_index.md` สรุปรายเล่ม:
   | เล่ม | จำนวนหน้า | ชนิด (ข้อความ/สแกน/ผสม) | Activity ที่ครอบคลุม (พร้อมช่วงหน้า) | ตำแหน่งรหัส LAW | ตำแหน่งรหัส SDD | ตำแหน่ง Page Code | หมายเหตุ |
   - ระบุช่วงหน้าที่พบรหัสแต่ละประเภท และตัวอย่างรูปแบบรหัสที่พบ (เช่น `LAW-xxx`, `SDD-xxx`)
   - ระบุหน้าที่เป็น OCR และความเสี่ยงความแม่นยำ
5. รายงานผู้ใช้: รายการไฟล์ที่สร้าง, สรุปจาก `_index.md`, คำเตือน OCR (ถ้ามี) และ Activity ที่ยังหาเล่มอ้างอิงไม่เจอ
