# ecmis-trace

เติมและอัปเดต E-CMIS Master Activity Template จากเล่มเอกสารและ source code ทีละ Activity
กติกาทั้งหมดอยู่ใน `CLAUDE.md`

## วางไฟล์ไว้ที่ไหน

| โฟลเดอร์ | ใส่อะไร |
|---|---|
| `input/docs/` | เล่มเอกสาร (PDF / DOCX / PPTX / XLSX / รูปภาพ) — แหล่งความจริงหลัก |
| `input/code/` | source code หรือไฟล์ข้อความที่ระบุ path ไป repo (ไม่มีก็ได้) |
| `template/` | template ต้นฉบับ (วางไว้แล้ว **ห้ามแก้**) |

ไฟล์ `.doc` / `.ppt` / `.xls` แบบเก่า ให้บันทึกเป็น `.docx` / `.pptx` / `.xlsx` ก่อน

โฟลเดอร์ที่ระบบสร้างเอง: `work/docs/` (เล่มแปลงเป็นข้อความ), `work/extract/` (ข้อมูลราย Activity), `output/` (ไฟล์ส่งมอบไฟล์เดียว), `output/backup/` (สำรองก่อนแก้ทุกครั้ง)

## วิธีใช้ — คำสั่งเดียว

```
/ecmis 5
```

ระบบจะพาทำครบทุกขั้นเอง และหยุดถามเฉพาะ 2 จุด

1. **ตรวจความพร้อม** ตรวจว่าวางไฟล์ถูกที่ และติดตั้งตัวแปลงเอกสาร (markitdown) ให้ถ้ายังไม่มี
2. **เตรียมเอกสาร** แปลงเล่มเป็นข้อความด้วย markitdown โดยแปลงเฉพาะเล่มใหม่หรือเล่มที่เปลี่ยน
   - PDF อ้างอิงด้วยเลขหน้า, PPTX ด้วยเลขสไลด์, DOCX ด้วยหัวข้อ
   - หน้าที่เป็นภาพสแกนหรือข้อความไทยเพี้ยน Claude จะอ่านจากภาพแทน และติดป้าย `[อ่านจากภาพ]` ให้คนตรวจทาน
3. **สกัดข้อมูล** Activity 5 → ⏸ **จุดตรวจ 1:** ดูสรุปและตอบคำถามที่หาในเล่มไม่เจอ
4. **เทียบกับโค้ด** ถ้ามีโค้ดใน `input/code/`
5. **อัปเดต Excel** → ⏸ **จุดตรวจ 2:** ยืนยันรายการเพิ่ม/แก้/ลบ (เลือก ยืนยันทั้งหมด / ยืนยันแต่ไม่ลบ / ขอแก้บางรายการ / ยกเลิก)
6. **ตรวจไฟล์ output** อัตโนมัติ แล้วสรุปผล

ถ้างานค้างกลางทาง ให้สั่ง `/ecmis 5` ซ้ำได้ ระบบจะเสนอให้ใช้ผลเดิมที่ทำไว้แล้ว
